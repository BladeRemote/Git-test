# Common Ground — GCD Finder

A single-page, self-contained website that helps kids aged 12–16 find the
**greatest common divisor (GCD)** of any set of numbers — and understand
*why* the answer is what it is, not just get a number back.

Live artifact: https://claude.ai/artifact/YMYabjnmssFJs3ykyGccdD

## What it does

- **Number bench** — add 2 to 8 whole numbers as chips, remove any of them,
  then hit "Find the GCD."
- **Two explanations, one answer** — toggle between:
  - *List the factors* — every number's full factor list, with the shared
    ones highlighted.
  - *Euclid's shortcut* — the actual division steps (`a = b×q + r`) the
    Euclidean algorithm uses to reduce the numbers pairwise.
- **Why it matters** — three short, concrete real-world uses (splitting food
  evenly, simplifying a fraction, tiling a wall) instead of abstract
  definitions.
- **Practice arena** — auto-generated challenges (always solvable with a
  clean integer answer), an answer box, and a running score + streak
  counter to make repeat practice feel like a mini game.

## Running it locally

Just open the file in any modern browser:

```bash
open gcd-finder.html        # macOS
# or double-click it in Finder/Explorer, or drag it into a browser tab
```

No installation, no `npm install`, no server required.

## How the math works

- **GCD of two numbers** — standard Euclidean algorithm (repeated
  `a, b = b, a % b` until `b` is 0).
- **GCD of more than two numbers** — reduced pairwise, left to right:
  `gcd(a, b, c) = gcd(gcd(a, b), c)`.
- **Practice challenges** — generated by picking a random "seed" GCD (2–12)
  and multiplying it by random small factors, which guarantees every
  challenge has a clean, findable answer.

All of this runs in plain JavaScript (`<script>` at the bottom of the file)
— no libraries, no external calculation service.

## Design notes

- **Fonts**: Space Grotesk (headlines, numbers, buttons) + Atkinson
  Hyperlegible (body text, chosen for readability). Loaded from Google
  Fonts — the only external dependency.
- **Palette**: deep teal-navy background with amber, coral, and green
  accents — deliberately not the pastel/primary-color look typical of
  "kids' apps," since the target age group tends to disengage from
  anything that reads as made for younger children.
- **Motion**: one deliberate animation (the number chips "snap" when a
  result is found) rather than animating every element; respects
  `prefers-reduced-motion`.
- **Accessibility**: visible keyboard focus states, `aria-live` regions for
  the result and feedback text, labelled inputs, and sufficient color
  contrast against the dark background.

## Privacy

Nothing is stored or sent anywhere. Numbers, score, and streak all live in
page memory only — refreshing the page clears everything.

## Customizing

- **Challenge difficulty**: adjust the ranges in `randInt(...)` inside
  `newChallenge()` in the `<script>` block.
- **Max numbers on the bench**: change the `numbers.length >= 8` check in
  `addNumber()`.
- **Color palette**: all colors are CSS variables at the top of the
  `<style>` block (`--bg`, `--amber`, `--coral`, `--green`, etc.) — edit
  those to restyle the whole page.
